# Wise101 Static React Page

A responsive React/Vite landing page inspired by the supplied Wise101 banner.

## Included

- Livestreaming
- Digital Marketing
- Event Management
- Instagram, YouTube, Facebook and Spotify links
- WhatsApp contact button for **0415 872 398**
- Wise101 website link
- Responsive mobile layout
- Original supplied banner preserved at `public/wise101-reference.png`

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production files are generated in `dist/`.
